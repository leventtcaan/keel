## Neden böyle
- Ağ yalnız `privacy`'de (mevcut `EgressRuleTests`): gerçek adaptör geldiğinde de HTTP oradan geçecek (ADR-042 #5).
- "Rıza var mı" yetmez: rıza **kime** verildi? Yapılandırma bir sağlayıcıyı, rıza başka birini anarsa çağrı reddedilir.
- Harcama limiti / anahtar: gerçek çağrı yok (ADR-041) → yayına çıkarken (kart kriteri "ertelendi").
