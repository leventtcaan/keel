## Neden böyle
- Dokploy/Appwrite değil düz Compose (ADR-064 #6): her satır repoda, testli, anlatılabilir.
- Yedek sunucuda **şifrelenir**, özel anahtar yalnız Mac'te: sunucu ele geçirilse yedekler okunamaz. Mac **çeker**, sunucu itmez (NAT, saldırı yüzeyi).
- Süreler tek dosyada (`retention.env`); politika ve envanter testle ona bağlı (K2).

## Kanıt (6 Eki, canlı)
`/health` HTTP/2 200, Let's Encrypt (3 Oca 2027), HTTP → 308; ilk sürüm 0 yeniden başlama, 8.169 besin; yedek → Mac → prova **38 tablo / 22.817 satır eşit**; root SSH reddedildi.
İnceleme 2 kritik + 9 önemli; canlı koşu 3 hata daha (iç içe `$$`, `psql` hatada 0 döner, openrsync + `pipefail`/SIGPIPE) — hepsi testle.

## Soru bankası
1. Bir imajı neden sürüm **ve** özetle (`@sha256:`) sabitleriz?
2. `internal: true` ağı neyi engeller; backend neden iki ağda?
3. Caddy sertifikayı nasıl alır (HTTP-01)? 80. port neden açık?
4. Yedek neden sunucuda şifrelenir, Mac neden çeker?
5. `psql` bir SQL hatasında neden 0 döner, ne yapmalı?
6. `set -o pipefail` + `| head` neden bir komutu "başarısız" yapabilir?
7. Geri yükleme provası neden canlı veriyle değil yedeğin kendi sayımıyla karşılaştırır?
