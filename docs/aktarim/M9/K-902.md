## Neden böyle
- **İlk tasarım yanlıştı (ADR-066 Ek 1):** `files` komutu istemciden gelen `deploy/`'u kabul ediyordu → zorunlu komutun kendisi değişebiliyordu → çalınan CI anahtarı = root. Ders: zorunlu komut, değiştirebileceği bir dosyada durursa kilit değildir; sunucu yalnız "hangi commit"i alır, kodu güvendiği yerden kendisi çeker.
- Depo yok: GHCR ya imajı herkese açar ya VPS'e yeni bir sır koyar.

## Kanıt (6 Eki, canlı)
CI anahtarıyla: kabuk komutu, `files`, `main`'de olmayan commit → reddedildi. #407 birleşti → Deploy koşusu imajı derledi, gönderdi, yayına aldı (`805150a`, 0 yeniden başlama); sonraki doküman commit'i → "nothing the server runs changed" → atlandı.
