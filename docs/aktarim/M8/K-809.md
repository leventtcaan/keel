# K-809 · Paywall'ın yasal adresleri derleme yapılandırmasında (ADR-057 D3, ADR-059 #3)

> Durum: **aktarılmadı**. Önce K-702 (paywall, `subscription/links.ts`), K-706 (kapı), K-801 (sayfalar).

## Projede nerede
| # | Basamak | Proje yeri |
|---|---|---|
| 1 | `EXPO_PUBLIC_TERMS_URL`, `EXPO_PUBLIC_PRIVACY_URL` — yalnız `production` (mağaza) profilinde | `apps/mobile/eas.json` |
| 2 | Yayın kökü: `url` + `baseurl` | `docs/yasal/site/_config.yml` |
| 3 | Test: dev-client olmayan her profil satabilir (`legalComplete`), adresler = `url + baseurl + permalink`; dev-client profilinde adres yok | `src/__tests__/legal-addresses.test.ts` |

## Neden böyle
- **`EXPO_PUBLIC_*` derleme anında gömülür:** Metro, `process.env.EXPO_PUBLIC_X` okumasını değerle değiştirir; bu yüzden statik yazılır (`links.ts`).
- **Neden `eas.json`, neden `.env` değil:** gizli değil; Expo `env` alanını "commit edeceğin değerler" için söylüyor. `.env` git dışı, mağaza derlemesine taşınmaz.
- **Neden dev profilinde yok:** geliştirme istemcisi JS'i yerel Metro'dan alır; Metro `EXPO_PUBLIC_*`'ı kabuktan ya da `.env`'den gömer, `eas.json`'dan değil
  (inceleme). Yerelde gerekirse `.env`'e yazılır.
- **Etkisi:** mağaza derlemesinde (iki adres + RevenueCat anahtarı) zorunlu paywall kapısı çalışır (ADR-058); geliştirmede açık kalır.
- **Neden test adresi sayfaya bağlıyor:** sayfanın `permalink`'i değişirse paywall ölü bağlantı göstermesin.

## Kanıt
RED 7 assertion → yeşil; inceleme: dev profili düzeltildi. M10'da alan adı değişince iki dosya + test birlikte.

## Soru bankası
1. `EXPO_PUBLIC_` önekli bir değişken neden sır taşımamalı?
2. Geliştirme istemcisinde `eas.json › env` neden JS'e ulaşmaz?
3. Adres değişirse hangi iki dosya değişmeli, hangi test yakalar?
