## Satır satır
1. **`record` (`:38-66`)** — ardışık hafta kontrolü → plan yoksa atla → oran ≥ çizgi: say + seri++ + kaçma sayacını sıfırla;
   değilse kaçma sayacı++ ve 2 olduysa seri = 0. Kümülatif sayaç hiç azaltılmaz.
2. **`weekStartOf` (`:73-74`)** — `Instant` (evrensel an) → ev saat diliminde tarih → o haftanın Pazartesi'si. Telefonun o anki
   saat dilimi hiç kullanılmaz; motor makinenin saat dilimini okuyamaz (`EnginePurityTests`).

## Öz-denetimin yakaladıkları
- "Affı" bozan mutasyon (iki **ayrı** kaçan hafta seriyi bitirsin) 12 testten sağ çıkıyordu → iki özellik testi.
- Eksik haftalar sessizce "plan yok" sayılıyordu → 3 hafta kaybolan kullanıcının serisi bozulmuyordu → ardışıklık şartı.
- Tavan haftanın toplamındaydı → fazla antrenman kaçan beslenmeyi telafi ediyordu (U7 ihlali) → dört tür ayrı modellendi.
