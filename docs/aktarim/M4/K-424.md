## Basamaklar
| # | Basamak | Proje yeri |
|---|---|---|
| 1 | Süperset = setin üstünde bir kimlik (`supersetId`, telefon üretir); ayrı kayıt yok, grup setlerden türetilir | V23, `NewSet` |
| 2 | Kendi hareketi: ad + **motorun ihtiyacı olan sınıflama kullanıcıya sorulur** (bileşik/izole, yük modeli, ekipman, tek taraf) — tahmin edilmez (U1) | `NewCustomExercise` |
| 3 | Katalogun kuralı aynen: bodyweight ekipman ⇔ bodyweight yük (kod + DB `check`) | `save`, V23 |
| 4 | Kimlik `custom:<uuid>`; set doğrulaması katalogda ya da sahibinin hareketlerinde arar, sonra aynı `SetRules` | `WorkoutController.log` |
| 5 | Program katalogdan kalır → motorun haftalık okumaları (program hareketleri) kendi hareketini görmez; bitişteki "temiz değil" listesinde kabul, etkisiz | `ProgramController`, `finish` |
| 6 | Silme/düzenleme yok (setler anıyor); 100 hareket, 60 kod noktası — ayrı yapılandırma kaydı (`keel.training.custom-exercise`) | `Limits` |
| 7 | Antrenman verisi: rıza yok (ADR-026), dışa aktarımda var, hesapla silinir | `TrainingAccountData` |
