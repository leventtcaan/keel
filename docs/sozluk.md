# Sözlük

> Terim ilk geçtiğinde buraya bakılır; yeni terim çıkınca buraya eklenir. Terim İngilizce kalır, açıklama Türkçe.

## Alan (fitness · beslenme)
| Terim | Açıklama | Kaynak |
|---|---|---|
| **RIR** (Reps In Reserve) | Setin sonunda "cepte kalan" tekrar sayısı. RIR 0 = tükeniş, RIR 1 = bir tekrar daha yapabilirdin | `ham/guray/G1-antrenman.md` K-5 |
| **Working set** | Isınma olmayan, tükenişe yakın (RIR 0-1) giden gerçek çalışma seti | G1 K-16 |
| **Mechanical tension** | Kasın yük altında gerilmesi; hipertrofinin tek hedefi kabul edilir (Güray aksiyomu) | G1 K-1 |
| **e1RM** (estimated one-rep max) | Ağırlık × tekrardan hesaplanan tahmini tek tekrar maksimumu; efor bazlı ilerleme metriği | `ham/B-antrenman.md` §6.4 |
| **Total volume** | set × tekrar × kg. Rakiplerin ana metriği; efor artıranı cezalandırdığı için bizde ana metrik değil | B §6.4 |
| **Double progression** | Önce tekrar aralığının üstüne çık, sonra ağırlık ekle | `ham/H3-bosluk-literatur.md` B4 |
| **Deload** | Yorgunluk birikince hacmi/yükü geçici düşürme. Güray'da takvimsel değil, sinyal tabanlı | `ham/guray/G7-whisper-arsiv.md` K-66…K-78 |
| **Maintenance / TDEE** | Kilonun sabit kaldığı günlük kalori. Formülle değil **gözlemle** bulunur | `03-guray-karar-omurgasi.md` §2.2 |
| **Deficit / surplus** | Maintenance altı (yağ kaybı) / üstü (kas kazanımı) kalori | — |
| **Cut / bulk** | Kalori açığı fazı / fazlası fazı | G3 |
| **Recomp** | Aynı anda yağ kaybı + kas kazanımı. Güray natürelde verimsiz buluyor | G3 |
| **Trend weight** | Günlük tartının hareketli ortalaması; su gürültüsünü (SD ≈0,42 kg) süzer | `ham/H1-olcum.md` |
| **WHtR** (waist-to-height ratio) | Bel ÷ boy. ≥0,50 eşiği, cinsiyetten bağımsız (NICE NG246) | H1 · `ham/J1-cinsiyet.md` |
| **NEAT** | Egzersiz dışı günlük hareketin yaktığı enerji (adım vb.). Diyette ilk çöken şey | G5 T-13 |
| **RED-S / LEA** | Düşük enerji mevcudiyeti sendromu. EA = (alım − egzersiz) / yağsız kütle; ≤30 kcal/kg FFM/gün = LEA | J1 (IOC 2023) |
| **SCOFF** | 5 soruluk yeme bozukluğu tarama anketi; ≥2 pozitif → projeksiyon kapalı | `ham/H2-projeksiyon.md` |
| **Consistency** | Günlük sayımız: haftanın planlı eylemlerinden (antrenman, protein, adım, tartı) yapılanların oranı | `04-faz3-urun.md` §7 |

## Ürün · pazar
| Terim | Açıklama |
|---|---|
| **CAT** (Computerized Adaptive Testing) | Sadece belirsizliği en çok azaltan soruyu sorup yeterince emin olunca susan soru modeli; "veri talebi"nin mekanizması |
| **Sycophancy** | Modelin kullanıcıya hak vermeye eğilimi. U1/U2 bunun için var |
| **ASO** | App Store Optimization — mağaza aramasında sıralama |
| **LTV / CAC / CPI** | Kullanıcı başı ömür boyu gelir / edinme maliyeti / kurulum başı maliyet |
| **Hard paywall** | Ücretsiz katman yok; deneme sonrası ödeme |

## Mühendislik
| Terim | Açıklama |
|---|---|
| **Modular monolith** | Tek uygulama, içeride sınırları testle korunan modüller (Spring Modulith) |
| **Deterministic** | Aynı girdi → her zaman aynı çıktı. Karar motorunun temel özelliği |
| **Contract-first** | Önce API sözleşmesi (OpenAPI) yazılır, kod ve istemci ondan türetilir |
| **TDD** | Önce test, sonra testi geçiren en basit kod |
| **ADR** (Architecture Decision Record) | Bir mimari kararın ne/neden/alternatif kaydı |
| **Provenance** | Bir kuralın/parametrenin kaynağı (hangi araştırma, hangi kural no) |
