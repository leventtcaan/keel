## Dış kapılar (Levent'in — tahmin etme, engellemeyen işe geç, DURUM'a yaz)
- **Hukuki metinler (Levent; gerekirse avukat):** gizlilik politikası, kullanım şartları, sağlık feragatnamesi. Agent **taslak** yazar (sade
  İngilizce, toplanan her veri + amacı + saklama süresi + üçüncü taraflar adıyla), hukuki onay vermez; "taslak — hukuki inceleme bekliyor"
  diye işaretli kalır. Soru 57 (rıza metinlerinin hukuki bakışı) burada kapanır ya da Levent'e devredilir.
- **Vergi / W-8BEN / GVK 20-B / Paid Applications (Levent + mali müşavir):** K-805. Agent yalnız neyin sorulacağını listeler; vergi tavsiyesi
  vermez.
- **App Store Connect beyanları (Levent onayı):** gizlilik etiketi (App Privacy), yaş derecelendirmesi anketi, erişilebilirlik etiketi.
  Agent cevapları **gerekçeli taslak** olarak hazırlar (envanterden); App Store Connect'e Levent girer.
- **Metinlerin yayın yeri (Levent):** politika ve şartlar herkese açık bir URL ister (App Store ve paywall — ADR-057 D3:
  `EXPO_PUBLIC_TERMS_URL`, `EXPO_PUBLIC_PRIVACY_URL`). Alan adı / barındırma ürün adına bağlı (M10) → geçici çözüm Levent'e sorulur
  (ör. GitHub Pages; repo public). Para gerektiren bir şey varsa sor.
- **Veri dışarı:** yeni bir üçüncü taraf akışı yok; envanter mevcut akışları (RevenueCat — ADR-012 Ek 1; AI sağlayıcısı — ADR-044, rıza
  ADR-007) adıyla yazar. Envanterle kod çelişirse kod doğrudur, metin düzeltilir.
- **Cihaz:** erişilebilirlik (K-807) VoiceOver/Dynamic Type için simülatör ister → disk (simülatör dyld önbelleği ~3 GB yeniden üretilir).
  2 GB altında başlama, Levent'e sor; olmazsa testle denetlenebilen kısım (etiketler, `allowFontScaling`, rol/etiket taraması) + cihaz adımı DURUM'a.

## Senkron kuralı (her part'ın BAŞINDA — atlanmaz)
1. `oturum-baslat` (DURUM + son 3 oturum + git + açık PR'lar + Dependabot).
2. `DURUM.md › ## M8 ilerleme` oku (Part 1'de: `## M7 ilerleme › Part 2 ÇIKIŞ = M7 ÇIKIŞ`): önceki part'ın **ÇIKIŞ** bloğu var mı, her madde
   doğru mu? Git ile doğrula (`gh pr list --state merged --limit 20`, `git worktree list`, `main` temiz mi). Yarım part ya da `M8-partN-devam.md`
   varsa **önce onu bitir**. DURUM ile git çelişirse git doğrudur. Ana checkout ayrık HEAD'se `origin/main`'e çek.
3. Bu part'ın görevlerinin `depends_on`'ı `done` mı? Değilse dur, DURUM'a yaz.
4. Disk: `df -h ~` (5 GB altı → önbellekleri temizle; 2 GB altıysa dur, sor).
