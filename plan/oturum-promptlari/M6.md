# M6 · İlerleme — dört part (ortak kurallar + devralınan kriterler)

> M6 tek session'da değil, **dört part** hâlinde, ayrı session'larda sırayla verilir (haftalık token sınırı; 14 görev, biri L
> "başlamadan önce ikiye bölünür"). Her part'ın prompt'u kendi dosyasında: `M6-part1.md` … `M6-part4.md`. Bu dosya dördünün
> **ortak** talimatıdır; her part bunu okur. Hafıza sohbette değil **dosyalardadır**: `DURUM.md › ## M6 ilerleme` tek doğru
> kaynaktır (Part 1 başında açılır). Hedef (yol-haritasi › M6): "gelişiyorum" duygusunu **kanıtla** vermek — karşılaştırma çıpası,
> efor grafikleri, projeksiyon. **Sayı motordan/veritabanından; görsel cihazda; aralık daima (U5); yağ yüzdesi yok (U4).**

## Dış kapılar (Levent'in — tahmin etme, engellemeyen işe geç, DURUM'a yaz)
- **Sağlık/regülasyon — K-607 SCOFF ve K-606 projeksiyon:** yeme bozukluğu taraması ve vücut şekli görseli hassas. Part 2'nin
  **başında** AskUserQuestion: SCOFF metni (5 soru, kaynak ve sürüm), pozitifte gösterilecek destek kaynağı (ülkeye göre — TR/US?),
  cevabın saklanmaması (V4 benzeri), projeksiyonun kapı eşikleri (18 yaş, BMI<20, SCOFF ≥2 — kaynak `arastirma/`). Cevap ADR'ye.
  Cevap gelene kadar kapı **kapalı** kalır (özellik açılmaz) — kod kapıyı varsayılan kapalı yazar.
- **Fotoğraf (V1):** ilerleme fotoğrafı **hiçbir zaman** ağa gitmez (K-601 "ağa gitmediğini gösteren test"). Öğün fotoğrafı yolu
  (K-514/K-408, ADR-046) ile karıştırma: o, AI rızasıyla tek bir öğün fotoğrafıdır; ilerleme fotoğrafının yolu yoktur.
- **Cihaz:** K-308 (development build) — K-601 kamera kılavuzu, K-609 HealthKit okuması, K-515/K-510/K-426 cihaz adımları ancak cihazda
  görülür. Yapılmadıysa kod + test + "Expo Go'da yok/simülatörde" yoluyla biter, cihaz adımı DURUM'a.
- **Disk:** Levent Docker'ı temizlemediyse yerelde DB testi ve simülatör yok (soru 80, hafıza `disk-docker-ajan`). Native derleme 3-5 GB.

## Senkron kuralı (her part'ın BAŞINDA — atlanmaz)
1. `oturum-baslat` (DURUM + son 3 oturum + git + açık PR'lar + Dependabot).
2. `DURUM.md › ## M6 ilerleme` oku (Part 1'de: `## M5 ilerleme › Part 4 ÇIKIŞ = M5 ÇIKIŞ`): önceki part'ın **ÇIKIŞ** bloğu var mı,
   her madde doğru mu? Git ile doğrula (`gh pr list --state merged --limit 20`, `git worktree list`, `main` temiz mi). Yarım part ya
   da `M6-partN-devam.md` varsa **önce onu bitir**. DURUM ile git çelişirse git doğrudur. Ana checkout ayrık HEAD'se `origin/main`'e çek.
3. Bu part'ın görevlerinin `depends_on`'ı `done` mı? Değilse dur, DURUM'a yaz.
4. Disk: `df -h ~` (5 GB altı → önbellekleri temizle; 2 GB altıysa dur, sor).

## Senkron kuralı (her part'ın SONUNDA)
`DURUM.md › ## M6 ilerleme` altına **"Part N ÇIKIŞ (tarih)"**: birleşen görevler + PR no · açık PR/worktree · kalan iş ·
sonraki part'ın bilmesi gereken teknik kararlar (dosya yolu ile) · yeni sorular. Backlog `status` +
`python3 tools/sync_backlog.py --apply`. `main`'e commit + push. Kısa Türkçe özet ver ve dur (aktarım yok).

## Bağlam / token koruması (hafıza: baglam-devri)
Her görev bitince DURUM tablosu; bağlam dolmaya yaklaşırsa görev sınırında dur, yarım işi dalında commit + push,
`M6-partN-devam.md` + DURUM › DEVAM NOKTASI. Arka plan ajanının sonucu gelince **önce dosyaya**.

## Her görev döngüsü (M5.md ile aynı — değiştirme)
gorev-baslat → test önce (geçerli RED: assertion; derleme hatası/eksik modül RED değil → önce iskelet) → kod → `npm run check` /
saf testler (`DOCKER_HOST=tcp://127.0.0.1:1 ./gradlew test`, saf/DB sayımı ayrı; DB testleri CI'da) → ekran varsa simülatörde kendin
doğrula (disk izin verirse; görüntü `docs/aktarim/M6/img/`, `sips -Z 1000`) → pr-review-toolkit ajanları (code-reviewer +
pr-test-analyzer; talimata "Docker açma, Gradle DB testi koşma" yaz) → bulgular TDD ile + mutasyonla kanıt (backend
`plan/oturum-promptlari/mutate.py` yalnız saf test sınıfı, `MUT_DIR=<modül>`; mobil: mutantı uygula, jest, **yedekten** geri yükle,
bir kontrol mutantı) → `docs/aktarim/M6/<K-ID>.md` + README → PR `gh pr merge --auto --squash` (**inceleme bitmeden auto-merge
açma**) → ccd_pr `get_status` → DURUM › M6 ilerleme. Motor kuralı: skill `kural-ekle` (kaynak + parametre + test, U14).
