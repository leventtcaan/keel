## Senkron kuralı (her part'ın BAŞINDA — atlanmaz)
1. `oturum-baslat` (DURUM + son 3 oturum + git + açık PR'lar + Dependabot).
2. `DURUM.md › ## M5 ilerleme` oku (Part 1'de: `## M4 ilerleme › Part 4 ÇIKIŞ = M4 ÇIKIŞ`): önceki part'ın **ÇIKIŞ** bloğu
   var mı, içindeki her madde doğru mu? Git ile doğrula (`gh pr list --state merged --limit 20`, `git worktree list`,
   `main` temiz mi). Yarım part ya da `M5-partN-devam.md` varsa **önce onu bitir**. DURUM ile git çelişirse git doğrudur.
3. Bu part'ın görevlerinin `depends_on`'ı `done` mı? Değilse dur, DURUM'a yaz.
4. Disk: `df -h ~` (5 GB altı → önbellekleri temizle; hâlâ azsa dur, sor).

## Senkron kuralı (her part'ın SONUNDA)
`DURUM.md › ## M5 ilerleme` altına **"Part N ÇIKIŞ (tarih)"**: birleşen görevler + PR no · açık PR/worktree · kalan iş ·
sonraki part'ın bilmesi gereken teknik kararlar (dosya yolu ile) · yeni sorular. Backlog `status` +
`python3 tools/sync_backlog.py --apply`. `main`'e commit + push. Kısa Türkçe özet ver ve dur (aktarım yok).
