## Senkron kuralı (her part'ın BAŞINDA — atlanmaz)
1. `oturum-baslat` (DURUM + son 3 oturum + git + açık PR'lar + Dependabot).
2. `DURUM.md › ## M9 ilerleme` oku (Part 1'de: `## M8 ilerleme › Part 2 ÇIKIŞ = M8 ÇIKIŞ`): önceki part'ın **ÇIKIŞ** bloğu var mı, her madde doğru mu?
   Git ile doğrula (`gh pr list --state merged --limit 20`, `git worktree list`, `main` temiz mi). Yarım part ya da `M9-partN-devam.md` varsa **önce onu
   bitir**. DURUM ile git çelişirse git doğrudur. Ana checkout ayrık HEAD'se `origin/main`'e çek.
3. Bu part'ın görevlerinin `depends_on`'ı `done` mı? Değilse dur, DURUM'a yaz.
4. Disk: `df -h ~` (5 GB altı → önbellekleri temizle; 2 GB altıysa dur, sor). EAS derlemesi bulutta (yerel disk istemez); yerel native derleme ~3-5 GB.
