## Senkron kuralı (her part'ın BAŞINDA — atlanmaz)
1. `oturum-baslat` (DURUM + son 3 oturum + git + açık PR'lar + Dependabot).
2. `DURUM.md › ## M3 ilerleme` oku: önceki part'ın **ÇIKIŞ** bloğu var mı, içindeki her madde doğru mu?
   - Git ile doğrula: söylenen PR'lar gerçekten birleşmiş mi (`gh pr list --state merged --limit 20`), `main` temiz mi,
     açık worktree var mı (`git worktree list`).
   - Önceki part yarım kaldıysa (ÇIKIŞ yok ya da "kalan" dolu): **önce onu bitir**, sonra bu part'ın işine geç. Hiçbir
     birleşmiş işi baştan yapma.
   - DURUM ile git çelişirse: git doğrudur; çelişkiyi DURUM'a yaz, sonra devam et.
3. Bu part'ın görevlerinin `depends_on`'ı `done` mı (`plan/backlog.yaml`)? Değilse dur, DURUM'a yaz.

## Senkron kuralı (her part'ın SONUNDA)
`DURUM.md › ## M3 ilerleme` altına **"Part N ÇIKIŞ (tarih)"** bloğu: birleşen görevler + PR no · açık PR/worktree ·
kalan iş · sonraki part'ın bilmesi gereken teknik kararlar (dosya yolu ile) · yeni sorular. `main`'e commit + push.
Sonra kısa Türkçe özet ver ve dur (aktarım yok).

## Bağlam / token koruması (hafıza: baglam-devri)

- Bağlam dolmaya ya da hak bitmeye yaklaşırsa: **görev sınırında** dur; yarım görevi dalında commit'le + push'la;
  DURUM › DEVAM NOKTASI + `plan/oturum-promptlari/M3-partN-devam.md` (tam olarak nerede, sıradaki komut) yaz; commit.
- Uzun çıktıları (log, test sonucu) dosyaya yaz, sohbete özet al.

## Her görev döngüsü (değiştirme)
gorev-baslat → test önce (geçerli RED; derleme hatası/exception RED değil) → kod → `cd apps/mobile && npm run check`
(+ backend dokunulduysa `./gradlew build`) → ekranı iOS simülatöründe kendin doğrula (ekran görüntüsü) →
pr-review-toolkit ajanları (code-reviewer + pr-test-analyzer, gerekirse silent-failure-hunter) → bulguları TDD ile
düzelt, mutasyonla kanıtla (backend: `plan/oturum-promptlari/mutate.py`, tek test sınıfı; mobil: mutantı elle uygula,
jest koş, geri al) → `docs/aktarim/M3/<K-ID>.md` (basamaklar, satır satır yerler, canlı kanıt, soru bankası) + README →
PR `gh pr merge --auto --squash` → ccd_pr `get_status` (CI'yı gh ile yoklama) → DURUM › M3 ilerleme.
Paralel iş: git worktree (`../keel-<iş>`). Sözleşme değişirse `contracts`'ta `npm run generate` (CI `--check` yapar).
